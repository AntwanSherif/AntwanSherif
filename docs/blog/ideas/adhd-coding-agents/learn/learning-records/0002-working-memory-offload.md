# 0002 — The working-memory offload

**Date:** 2026-07-01
**Lesson:** `lessons/0002-the-working-memory-offload.html`

## What was taught
- Working-memory deficits in adult ADHD are real, moderate, across both phonological + visuospatial domains, and persist into adulthood (meta-analysis, 38 studies — **verified**).
- Mechanism: holding state in working memory costs energy; the executive-function fix is **cognitive offloading** — move state onto a durable surface.
- Bridge: "rename the sessions / memory files / let the agent hold context" = externalizing working memory. Not tidiness — a recognized EF intervention.

## Key insight
This is the series' first *tactic* and it's the strongest-evidenced one (the WM meta-analysis is verified). It converts a personal habit into a defensible claim — the exact move the whole playbook post needs to repeat: tactic ← named intervention ← peer-reviewed mechanism.
