# UTM Links — Copy-Paste Sheet

Base domain: `https://antwansherif.com` (`antwan.me` is an alias — swap freely)

---

## LinkedIn

```
# Website / profile field
https://antwansherif.com/?utm_source=linkedin&utm_medium=profile

# Post or article
https://antwansherif.com/?utm_source=linkedin&utm_medium=post
```

## GitHub

```
# Profile / README
https://antwansherif.com/?utm_source=github&utm_medium=profile
```

## Email signature

```
https://antwansherif.com/?utm_source=email_sig&utm_medium=bio
```

## CV / résumé (PDF link)

```
https://antwansherif.com/?utm_source=cv&utm_medium=pdf

https://antwansherif.com/cv?utm_source=cv&utm_medium=pdf
```

---

## With a campaign tag

Append `&utm_campaign=job_search_2026` to any link above when you want to
measure a specific push as a unit (e.g. an active job search window).

```
# Example: LinkedIn profile during a job search
https://antwansherif.com/?utm_source=linkedin&utm_medium=profile&utm_campaign=job_search_2026
```
